First, the reap in ralph-log.sh was changed from depth 2 to depth 3, which MOVED it rather than widening it: a run in the older `<slug>/<agent>-<pid>` layout now sits at a depth the reap no longer visits and is never collected, and those corpora exist on disk. Add the shallower case as a plain shell LOOP rather than a second `find`, because the test it needs is awkward to express as a find predicate:

Iterate the depth-2 directories with a glob (`for d in "$LOG_ROOT"/*/*; do ... done`). For each one: skip it unless it is a directory; skip it if it contains any subdirectory of its own; otherwise delete it if it is older than the same `-mmin` threshold the depth-3 reap uses. Guard the glob against matching nothing.

That subdirectory test is the whole point and must not be dropped. A run directory contains files and no subdirectories; a HOST directory contains run directories. Both sit at depth 2, a host's mtime tracks its newest child, so deleting depth 2 unconditionally destroys an aged host together with the live runs inside it. Do NOT reach for a depth RANGE like `-mindepth 2 -maxdepth 3` — that is exactly the unconditional delete just described, and this spec's gate has a control that fails on it. Do not identify a run by its NAME either: `<agent>-<pid>` is indistinguishable from a Kubernetes pod name like `harness-run-7`, which is why the host level is excluded by position everywhere else in the harness.

Second, the empty-directory prune. ralph-log.sh prunes only INSIDE the current run's own slug directory, so a wholly-expired OTHER spec keeps an empty host directory, which keeps its slug directory non-empty, which means the slug directory survives as an empty husk; ralph-status.sh prunes only at depth 1 below its root and has the same defect for the same reason. In each file replace the single prune with two passes rooted at the STORE ROOT rather than at one slug: first remove empty directories at depth 2, then at depth 1. The order is load-bearing — the outer pass can only see a slug directory as empty once the inner pass has removed the empty host directory inside it.
