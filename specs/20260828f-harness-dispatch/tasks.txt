T6: set the pod restart policy in the rendered Job, in scripts/dispatch/dispatcher.py. The Job's pod template spec currently omits `restartPolicy`, and a Kubernetes Job REQUIRES it to be either `Never` or `OnFailure` — without it the API server rejects the Job and it never runs at all. Set it to the string `Never`, alongside the existing pod-level fields. `Never` rather than `OnFailure` because the rendered Job already sets `backoffLimit` to 0: the loop owns its own retries, and letting Kubernetes restart the pod would start a second loop over the same spec. Change nothing else in the rendered object and no other function.
