T1: scripts/work-mutate.sh — the author-independent probe tool. Given a task dir and a commit (default HEAD), it copies the tree hermetically (gate-selftest's copy discipline: cp, strip .git, re-init, carry origin/main best-effort), derives probes FROM the commit's own diff — two curated operators in v1: revert-one-hunk and drop-one-added-line, skipping blank/comment-only lines (heuristic: leading #, //, --, ;) — applies one probe at a time, runs the task's gate bounded (GATE_SELFTEST_TIMEOUT), and prints one verdict line per probe: NOTICED (gate exited non-zero), UNNOTICED (gate passed the damaged work), HUNG; then a summary. Probe selection is DETERMINISTIC (ordered, sampled by a seed derived from the commit sha) and budgeted (RALPH_WORK_MUTANTS, default 4, 0 = generate nothing), so any ledger row is reproducible by re-running at that commit. The real tree is byte-identical after. Emission rides the 20260830f seam: SELFTEST_EVID set means one JSONL row per probe (ts, run id, spec, task, commit, operator, target, verdict, gate rc, probe diff, "kind":"work") plus a run_complete marker into .evidence/worksens-<slug>.jsonl; unset means not one byte. Exit 0 unless the TOOL errs — verdicts are data, never failure; the vocabulary deliberately never overlaps KILLED/SURVIVOR so telemetry cannot be read as enforcement.
T2: the loop measures sensitivity at the moment trust is minted, and it can never change a run. In ralph-build.sh, after a task's first green, after its corpus selftest passes, and after the commit LANDS (the commit is the reproducible probe unit), run work-mutate.sh on that commit with the budget; print exactly one summary line (work-sensitivity: N/M noticed) in the run output. NON-BLOCKING is the contract, gated both ways: the run's exit code, commit history, and retry behavior are byte-identical with RALPH_WORK_MUTANTS=0 and with the default, and an UNNOTICED probe stops nothing, retries nothing, resets nothing — equivalent-mutant noise treated as failure would teach operators to discount the whole signal (the warn-stays-warn rule, one layer down). Enforcement is OQ1, ratified only after the dogfood rows establish the equivalent-probe baseline.
T3: the rows become the research surface. mutant-ledger.py gains a work-sensitivity section rendered from .evidence/worksens-*.jsonl: UNNOTICED probes first with their diffs visible (the leads), then counts per task and operator; the section is visually and verbally separate from the corpus enforcement table and its header names the posture (telemetry — an UNNOTICED probe is a lead, not a conviction), so a future reader can never mistake sensitivity counts for gate failures; when no rows exist the section says so instead of vanishing (an absent section reads as an unbuilt feature, not an unmeasured fleet). .evidence/README.md documents the store beside selftest-*.jsonl with the enforcement/telemetry distinction in one sentence. This section is the seam the fleet-monitoring visualization consumes — the OQ3 judge-triage column lands here later, not in the loop.
